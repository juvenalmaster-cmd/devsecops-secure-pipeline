# ⚙️ Módulo 3 — GitHub Actions

## 🎯 Objetivo

Automatizar procesos DevSecOps utilizando GitHub Actions como plataforma CI/CD.

---

## 🧱 ¿Qué es GitHub Actions?

GitHub Actions es el sistema de automatización integrado en GitHub.

Permite ejecutar tareas automáticamente después de eventos como:

- git push
- pull requests
- cambios en ramas
